Link pg_glue_test with libdl on Linux hosts with glibc older than 2.34, or state that they are unsupported for zig build test

oruxe4 made zig/src/pg_glue_test.c (libpq_versions) call dladdr to print
which libpq the test loaded, which libpq-lines.sh checks. glibc moved dladdr
into libc in 2.34; on an older Linux host (Debian 11 has glibc 2.31) the
test executable built by zig/build.zig (glue_mod) also needs `-ldl`, which
build.zig does not add. Found by sol in the review round of oruxe4
(20261117-073007-5339); not verified: only macOS (M1) was available, where
dladdr is in libSystem and the test passes.

Question: should zig build test support Linux hosts with glibc < 2.34?
Options: add `glue_mod.linkSystemLibrary("dl", .{})` for Linux targets in
zig/build.zig and verify it on such a host | state in README "Running" that
the tests need glibc 2.34 or later on Linux (the servers themselves still
target the Lean toolchain's glibc 2.26 and are unaffected: the dladdr call
is only in the test).
