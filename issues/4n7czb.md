Link libzsrv.a against the glibc of Lean's toolchain on Linux

Reported on 2026-11-16 by the ekklesiai.org session (ekklesiai-org-8f, its deployment item fdgm4e, job 1fac932173480673-60): `lake build lsrv-site` in ekklesiai.org, pinning this repository at 37e1cdba, does not link on Debian 13 x86_64 (vps.frolow.dev; Zig 0.17.1, toolchain leanprover/lean4:nightly-2026-11-14, libpq-dev from Debian). ld.lld (Lean's bundled clang) reports undefined symbols `copy_file_range` (Threaded.zig:11722, Io.Threaded.fileWriteFilePositional) and `statx` (Threaded.zig:4063, Io.Threaded.fileStatLinux) in libzsrv.a, and one from Io.Threaded.posixExecveat (Threaded.zig:17433). The deployment is blocked on it.

Cause, checked by the coordinating session on macOS the same day: `extern_lib zsrv` (lakefile.lean) runs `zig build` for the native target, so on Linux Zig's std targets the host glibc (2.41 on trixie), while Lean links against its own glibc sysroot (`<toolchain>/lib/glibc/`, highest symbol version GLIBC_2.26 as the reporting session saw it). Cross-compiling zig/ with `-Dtarget=x86_64-linux-gnu.2.41`, `nm -u libzsrv.a` lists copy_file_range, statx and execveat; with `-Dtarget=x86_64-linux-gnu.2.26` it lists none of them (zig/build.zig takes `standardTargetOptions`).

Do: on Linux, make `extern_lib zsrv` pass `zig build` a target whose glibc is the Lean toolchain's (derive it from the toolchain where that is reliable, else state the value and its source next to the code, rechecked at each toolchain update); macOS stays native. Add to `./bench.sh` a check that does not need Linux: cross-build zig/ for x86_64-linux-gnu at that glibc and fail if the archive references copy_file_range, statx or execveat (or, better, any symbol the toolchain's glibc lacks, if that list is available on macOS). Include the target in the extern_lib's trace.
Check: `./bench.sh` exits 0 with the new check, and the check fails when the glibc is set to 2.41. The Linux link itself is verified by the ekklesiai.org session on vps.frolow.dev with the new pin; tell it (ekklesiai-org-8f) the commit.
