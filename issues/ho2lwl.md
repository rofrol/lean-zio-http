Deinitialize a loop only after every stop notify on it has returned (zio subset contract)

Follows vvxfl6 (the Async.notify / Loop.deinit race; upstream question https://github.com/lalinsky/zio/issues/927, opened 2026-11-16).
Decided by the user 2026-11-16: "pick something to unblock us if we are blocked" while upstream has not answered. The coordinating session picked, with sol (consult round 20261116-214352-aaa0), a supported-subset contract under AGENTS.md Rule 6: "a loop is deinitialized only after every notify() on its handles has returned, and no notify starts after its loop's teardown", grounded in the pinned zio 9bef33d (src/ev/completion.zig:668 `Async.notify`, src/ev/loop.zig:662 `wakeAsync`, `Loop.deinit`), written next to the code in zig/src/serve.zig, marked as not an upstream guarantee, and rechecked at each zio update; removed if upstream declares notify safe against concurrent deinit, replaced by a fork fix if upstream calls it a bug (that needs the user's go).
Design (sol): a per-loop mutex and a `retired` flag stored outside the loop and handle allocations. The signal thread takes the mutex, skips a retired loop, otherwise holds it through the whole `stop.notify()`, then unlocks. After `run()` returns, the loop thread takes the same mutex, marks the loop retired, deinits, then unlocks. The gate outlives both threads. Never take the mutex from a callback or while joining. A loop that ends for another reason retires at once; the signal thread's wait must also end on a coordinator event when every loop has ended without a signal, so joining it cannot hang. Check that completing the async does not itself free storage notify still touches.
Tests, no sleeps (Rule 10): a test-only hook just before backend.wake inside the notify path pauses it on an event handshake; inject socket readiness; observe run() return; the teardown's gate probe reports busy (exclusion shown); release notify, observe its return, then teardown. Separately: teardown first, then notification admission reports retired; a loop ending without a signal; the signal wait cancelled by the coordinator event. The existing reproducer from vvxfl6 must fail before and pass after where it applies.
Check: ./bench.sh exits 0; README "Transport tests" states the subset contract and the upstream issue.
